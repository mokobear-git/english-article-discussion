# 論文ディスカッション

英語論文と設問を読み込み、次の流れを音声会話で進める Web アプリ。

1. 論文の日本語訳を表示(ストリーミング)
2. 設問を1つずつ、選択肢つきのスモールステップ質問で解く
3. 考えをまとめて「こうですか?」と確認。OKで日本語の解答文を提示
4. 解答文を1文ずつ英訳させる。語彙ヒントつき。評価・訂正のうえ確定
5. 次の設問へ。確定した英文は「成果」タブにたまり、Markdown で保存できる

## 起動

Node.js 20 以上が必要。

```bash
npm install
```

```bash
export ANTHROPIC_API_KEY=sk-ant-...
```

```bash
npm start
```

ブラウザで http://localhost:3000 を開く。音声認識は Chrome / Edge / Safari で動作する(Firefox はテキスト入力のみ)。

API キーなしで画面だけ試す場合はモックで起動する。

```bash
npm run mock
```

## 使い方

- 論文・設問は PDF・テキスト・画像(png/jpeg/webp/gif)。複数ファイル可。本文の貼り付けも可。Word は PDF に変換して読み込む。
- 「開始」で訳文が流れ始める。訳文の表示中に、設問指導の最初の応答を裏で先に生成しておくため、「設問へ進む」を押すとすぐ始まる。
- 「設問へ進む」で会話モードが ON になる。
  - 話した内容は認識途中から画面に表示される。
  - 話し終えて約1.1秒の無音で自動送信(設定で変更可)。
  - アプリの応答は生成と並行して、1文ずつ即座に読み上げる。読み上げ終了後に自動で聞き取りを再開する。
  - 英訳を求める段階では、入力言語が自動で English に切り替わる。手動切替も可。
- 選択肢はボタンでも、「Bです」のような発話でも回答できる。
- 「ヒント」で追加ヒント。「停止」または Esc で読み上げ停止。
- 設定の「読み上げ中も聞き取る」を ON にすると、話し始めた時点で読み上げを止めて割り込める。スピーカーの音を拾うため、ヘッドホン使用時のみ推奨。
- 途中でページを閉じても、同じブラウザで開き直せば続きから再開する(記録はサーバーの `data/sessions/` に保存)。

## 応答速度に関する設定

環境変数で調整する。

| 変数 | 既定値 | 内容 |
|---|---|---|
| `MODEL` | `claude-opus-5-5` | 使用モデル |
| `DIALOG_EFFORT` | `low` | 対話ターンの思考量。`low` が最速 |
| `TRANSLATE_EFFORT` | `medium` | 全文翻訳の思考量 |
| `FAST_MODE` | 未設定 | `1` で Opus の fast モード(出力速度最大約2.5倍、料金2倍、Claude API のみ) |
| `PORT` | `3000` | ポート |

速度のための実装上の工夫:

- 応答はすべてストリーミング。画面表示と読み上げは最初のトークンから始まる。
- 論文・設問はプロンプトキャッシュに載せ、翻訳と全対話ターンで共有する。2ターン目以降の待ち時間が短くなる。
- 対話ターンは短く(3〜6文)返すよう指示している。
- 応答中に話しかけると、その応答を中断して新しい発話を処理する。

## 構成

```
server.js      HTTP サーバー、Claude API 呼び出し(ストリーミング)、セッション保存
prompts.js     システムプロンプト(指導手順・METAライン仕様)と各タスク指示
mock.js        MOCK=1 用の疑似応答
public/        画面(index.html / style.css / app.js)
```

- モデルは各応答の末尾に `<<<META {...}>>>` 行(設問番号・段階・選択肢・英訳対象文・確定英文など)を付ける。画面はこの行を表示・読み上げせず、選択肢ボタン、英訳対象カード、成果タブの更新に使う。
- 拒否応答(refusal)に備え、サーバー側フォールバック(`fallbacks: "default"`)を有効にしている。

## 注意

- マイクはセキュアコンテキスト(https または localhost)でのみ使用できる。スマートフォンから使う場合は https で公開する。
- 音声認識の精度・対応言語はブラウザに依存する。Chrome の音声認識は音声データを Google のサーバーに送る。
- 論文データは Anthropic API に送信される。
